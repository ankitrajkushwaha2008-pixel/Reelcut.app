# ReelCut

ReelCut is a browser-based video clip editor for creating vertical, square, and landscape clips.

## Features

- Local MP4, WebM, and MOV file editing
- Direct video-link and YouTube preview support
- Suggested segments
- Vertical, square, and landscape export
- Optional live face tracking
- Live browser speech captions and SRT export

## Run

Serve the repository with any static web server:

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Browser support

Video export is best supported in Chrome or Edge. Camera and microphone permissions require HTTPS or localhost.
